# Glossar

| Begriff | Bedeutung |
|---|---|
| Dokument | Ein abgelegtes Schriftstück: Original + PDF/A + Metadaten |
| Original | Die unverändert gespeicherte Eingangsdatei |
| PDF/A | Archivformat mit eingebettetem OCR-Text, durchsuchbar |
| Eingang | Quelle, aus der Dokumente kommen (Upload, Kamera, Ordner, IMAP, iCloud) |
| Zuordnung | Automatisches Füllen von Feldern und Tags durch das LLM |
| Feld | Feste Eigenschaft: Absender, Dokumentart, Datum, Betrag |
| Tag | Freies Schlagwort, mehrere je Dokument |
| Frist | Termin aus einem Dokument (Zahlung, Kündigung), mit Erinnerung |
| Privat | Markierung: Dokument nur für das anlegende Konto sichtbar |
| Haushalt | Gruppe von Konten, die einen gemeinsamen Bestand teilen |
| Worker | Eigener Prozess für Verarbeitung und Abholen |
| Intelligent invertiert | Darstellung: Helligkeit umgedreht, Farbton erhalten, Fotos original |
| Fristart | Kategorie einer Frist (Zahlung, Kündigung, Termin, Ablauf …) mit eigener Übernahme- und Vorlauf-Einstellung |
| CalDAV | Standardprotokoll zum Lesen/Schreiben von Kalendern, von iCloud unterstützt |
| Version | Eine Datei eines Dokuments: Original oder bearbeitete Fassung |
| Papierkorb | Ablage entfernter Versionen/Dokumente, 30 Tage wiederherstellbar |
| Stapel | Mehrere Briefe in einem Scan, werden in Einzeldokumente getrennt |
| Vertrag | Objekt mit Anbieter, Kosten, Laufzeit, Kündigungsfrist und zugehörigen Dokumenten |
| Preiserhöhung | Neuer Betrag eines Vertrags ist höher als der bisherige |
| Spike | Zeitbegrenzter Versuch, der eine technische Frage klärt |
